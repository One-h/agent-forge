# 飞书工作台设计规范

飞书工作台是日常查阅和操作界面。以“先找到会话或记录，再看细节、再做配置”为顺序；不为每个能力加一个首页区块。

## Token

基础 token 定义于 `apps/web/src/styles.css`，飞书使用 `apps/web/src/larkWorkspace.css` 的语义别名。颜色随 Forge 浅色/深色主题切换，组件不维护另一套色板。

| 用途 | Token | 约定 |
| --- | --- | --- |
| 工作面、输入背景、分隔线 | `--lark-surface`、`--lark-canvas`、`--lark-line` | 表格、消息和抽屉优先靠实底及细分隔线区分。 |
| 选中和出站 | `--lark-selected`、`--lark-outbound`、`--lark-outbound-border` | 珊瑚色是 Forge 的操作与选中语义；信息色仅区分机器人出站消息，不等于任务成功。 |
| 状态 | 全局 `--color-success`、`--color-warning`、`--color-danger` 及其浅底 | 用状态文字配合颜色，不单靠颜色表达结果。 |
| 文字 | `--lark-title-size`、`--lark-body-size`、`--lark-meta-size` | 当前为 20/13/12px，桌面与移动端层级一致；ID、时间和统计为辅助内容。 |
| 间距 | `--lark-pad`、`--lark-gap`、`--lark-compact-gap` | 当前为 16/12/8px。用于工作面内边距、同层区块和图标/控件组合。 |
| 交互与轮廓 | `--lark-control-size`、`--lark-radius`、全局 `--focus-ring` | 主要图标控件 36px，圆角 8px；键盘焦点可见，图标按钮有可访问名称及提示。 |

## 页面与交互

- **导航**：研发工作、飞书工作台、系统分组。原路由不变，当前项保留文字及选中提示。
- **页头**：复用 `LarkWorkspaceHeader`。一行标题、一个主要动作；刷新之类的重复动作使用带短标签提示的图标按钮。不以横幅或说明替代任务区域。
- **会话**：桌面并列列表和时间线；窄屏只显示其中一个。会话头只展示识别信息，技术 ID 默认收起但仍可展开和复制。点击消息仍进入原详情。
- **建群**：先看列表，点击“新建私有群”才展开抽屉。模型和人设保持可选；结果未确认时保留原请求、错误及重试，不在界面层补发新请求。
- **设置**：运行与人设、回复策略、会话记录分栏。方向键切换栏位；切栏不丢草稿。只在对应栏位显示其保存动作。
- **可用性**：保留加载、空状态、失败和重试。长名字、模型、错误和 ID 可换行或按语义截断，不撑破容器；不依赖图标或颜色作为唯一状态提示。

## 验收

检查 1440px 桌面和 390px 手机布局、浅色与深色模式，检查页面无横向溢出。用隔离响应验证会话信息展开、设置键盘与草稿保留、建群结果、手机列表返回。验收不得真实建群、改飞书配置或发送消息。
